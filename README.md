# hac_team

ハッカソンのチーム開発用のレポジトリです．
あげるときはコメント書いてください．

手順
1．git colne (URL)←URLはhac_teamレポジトリ開いたときにコピーできるとこがある
2．場所指定してなければホームにhac_teamフォルダができるので，githbにのせたいファイル（コピーがいいかも）をいれる
3．cd hac_team(作ったフォルダに移動）
4．git add （追加したいファイル名)
5．git commit -m "コメント追加" (新しく追加のときは-m，追加したファイルの修正コメントは-Am)
6．git push
